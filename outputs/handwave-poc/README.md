# Handwave desktop control

1. Double-click `start-cursor-helper.bat` and keep its window open.
2. Open the Handwave page and enable the camera.
3. Select **Control desktop**.
4. Move an open lime hand to steer the Windows cursor. Close your fist to press or drag; open it to release.
5. Press **Esc** at any time to stop desktop control.

The helper listens only on this computer (`127.0.0.1`) and accepts requests only from a locally served page.
